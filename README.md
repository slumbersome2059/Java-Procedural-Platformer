# Java-Procedural-Platformer
## Features of the Game
- Maze levels where each maze is randomly generated
- Sokoban Level where you push boxes onto certain squares(the levels are chosen out of a large pool of predefined levels) 
- Torch level where you can use a torch to save youself when landing on previous instances of your dead version and the goal is to jump to the end of the game
- Level instances placed at random locationsm with appropriate paths laid between them
## Experience that I Gained
- I used a ray casting algorithm to display the torch, which would be displayed as little triangles and you had to work out collisions of the rays of triangles
- Used A* algorithm to generate paths between levels
- Gained a good understanding in OOP and used inheritance and polymorphism
- Project management skills from having to plan a large project over a long amount of time
- Thought about testing with users 
- Learnt how to gather requirements from stakeholders effectively

## Playing the Game 
- To run the game run the DesktopLauncher(this is inside /desktop/src/com.mygdx.game/DesktopLauncher) once you open the file in an IDE
- Press W for up, A for left, S for down, D for right
- In the level with the different towers, first click on the screen to activate torch then use the mouse to move the torch
- The player only experiences gravity in the level with the towers, everywhere else there is no gravity
